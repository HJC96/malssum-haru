# 오늘의 말씀·정적 배포 QA 기록

> 2026-09-26 당시의 검증 기록이다. Spring Cloud 학습 랩과 아래 관련 테스트 명령은 2026-09-27 현재 제거되어 재실행할 수 없다.

- 검토일: 2026-09-26 (Asia/Seoul)
- 범위: 말씀 UI, 날짜별 로더/검증, 정적 배포 경계, 일독 계획 UI 회귀, Spring Cloud 로컬 학습 랩
- 배포: 하지 않음. AWS 자격 증명·외부 성경 제공처 API·LLM은 사용하지 않음.

## 결과

- 오늘 QT 화면은 준비된 날짜 artifact만 정확히 요청한다. 날짜 artifact가 없으면 이전 날짜로 fallback하지 않고 공식 QT 바로가기를 유지한다.
- `2026-09-26.json`은 개역한글판 시편 23:1·요한복음 3:16을 각각 구약/신약 단일 절로 검증한다. 역본과 저작권자 표기를 함께 제공하고 원문 문구를 수정하지 않는다. 각 절은 [시편 전사본](https://ko.wikisource.org/wiki/개역한글판/시편), [요한복음 전사본](https://ko.wikisource.org/wiki/개역한글판/요한복음) 출처를 제공한다. 편집 해설을 본문과 분리해 표시한다.
- 오늘의 말씀 제목과 날짜를 별도 줄에 중앙 정렬했다. `omalssum-react` 참고 레이아웃에 맞춰 회색 페이지 바탕, 좁은 중앙 흰 카드, 연한 파란색 제목면, 둥근 모서리와 인디고 공식 사이트 버튼을 사용한다.
- 독립 검토에서 날짜 불일치, 시차/언어 메타데이터, 정확한 날짜만 요청, 구약·신약 분류, 직접 링크, JSON 정적 경로, SPA 재작성 제외, CloudFront 날짜 artifact 캐시 갱신을 확인했다. S3 비공개 원본의 누락 객체가 403을 돌려주는 경우도 자료 없음으로 처리하고 이전 날짜로 fallback하지 않는다.
- 로컬 브라우저 `http://localhost:5174/?review=2`에서 개역한글 두 절·출처·저작권 표기·해설과 매일성경/생명의삶 외부 링크를 확인했다. 일독 계획의 드래그 동작은 자동 상호작용 테스트로 검증했고 실제 터치 기기 검수는 하지 않았다.
- 프로덕션 일일 자료는 현재 `2026-09-26` 한 날짜만 있다. 다음 날짜 자료를 준비하지 않으면 날짜 변경 후 안내 상태와 공식 링크가 보인다.
- `/daily-word/*`는 배포 산출물 경로를 통해 S3 정적 파일로 제공되고 CloudFront 무효화 대상에 포함된다. 제공처 취득·수집 스위치는 기본 off이다.
- 당시 Spring Cloud 학습 랩은 `labs/spring-cloud/`에 격리되어 있었으며, 이후 제품 범위 변경에 따라 제거했다.

## 남은 항목

- 해설은 제품/신학 전문가가 검수한 교단·성서학 기관의 공식 주석이 아니다. 추가 날짜 본문은 원문과 대조하고 동일성·출처표기를 확인해야 한다.
- 이후 날짜 artifact를 만들고 QA하지 않는 한 매일 말씀 기능은 당일 이후에 계속 표시되지 않는다. 자동 생성·예약 배포는 별도 비용·품질·권한 승인 과제로 남긴다.
- 모바일 실기기, 키보드 전용 드래그·터치 정렬, 인쇄 스타일은 별도 검수가 필요하다.
- AWS 배포 및 실제 CDN invalidation은 수행하지 않았다.
